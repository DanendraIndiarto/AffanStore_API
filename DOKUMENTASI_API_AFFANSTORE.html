AffanStore REST API

Dokumentasi Teknis & Panduan Integrasi Front End • NestJS + Prisma ORM

v1.0 Production Ready
1. Konfigurasi Lingkungan (Environment)
Base URL API (Lokal)
http://localhost:3000
Dokumentasi Interaktif Swagger
http://localhost:3000/api
Static File Server (Gambar Produk)
http://localhost:3000/uploads/<filename>
Format Header Autentikasi
Authorization: Bearer <access_token>
Status CORS: Sudah diaktifkan secara global di backend (app.enableCors()). Front End (React / Next.js / Vue / Vite) dapat langsung melakukan request tanpa kendala cross-origin.
2. Master Data & Enums Acuan
Nama Enum Nilai yang Valid Keterangan / Penggunaan
Role USER, ADMIN Hak akses akun. Default saat registrasi adalah USER.
PaymentMethod CASH, QRIS Metode pembayaran yang dipilih pembeli.
ShippingType COD, NON_COD Tipe pengiriman barang.
OrderStatus PENDING, PAID, CANCELLED Status perjalanan pesanan transaksi.
3. Aturan Bisnis Penting (Business Rules)
  • Sinkronisasi Pembayaran & Pengiriman:
    • Jika paymentMethod: "CASH", maka shippingType WAJIB "COD".
    • Jika paymentMethod: "QRIS", maka shippingType WAJIB "NON_COD".
    • Jika kombinasi tidak sesuai, backend akan mengembalikan error 400 Bad Request.
  • Manajemen Stok Otomatis: Saat checkout berhasil, stok produk otomatis berkurang. Jika pesanan dibatalkan (oleh User atau Admin), stok akan di-restock (dikembalikan) otomatis ke database.
  • Pembatalan Pesanan oleh User: User hanya dapat membatalkan pesanan miliknya yang masih berstatus PENDING.
4. Modul Autentikasi (`/auth`)
POST /auth/register PUBLIC
Mendaftarkan akun customer baru ke dalam sistem.
Request Body (application/json)
{
  "name": "Budi Santoso",
  "email": "budi@gmail.com",
  "password": "rahasia123" // Min 6 karakter
}
Response Sukses (201 Created)
{
  "id": 1,
  "name": "Budi Santoso",
  "email": "budi@gmail.com",
  "role": "USER",
  "createdAt": "2026-10-06T06:00:00.000Z"
}
POST /auth/login PUBLIC
Autentikasi akun dan mendapatkan JWT Token untuk request selanjutnya.
Request Body (application/json)
{
  "email": "budi@gmail.com",
  "password": "rahasia123"
}
Response Sukses (200 OK)
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "id": 1,
    "name": "Budi Santoso",
    "email": "budi@gmail.com",
    "role": "USER"
  }
}
5. Modul Produk (`/products`)
GET /products PUBLIC
Menampilkan seluruh katalog produk diurutkan dari yang terbaru.
Response Sukses (200 OK)
[
  {
    "id": 1,
    "name": "Sepatu Running Adidas",
    "description": "Sepatu lari sol empuk dan ringan",
    "price": 650000,
    "category": "Sepatu",
    "stock": 10,
    "imageUrl": "/uploads/product-171800000-12345.jpg",
    "isActive": true,
    "createdAt": "2026-10-06T06:00:00.000Z",
    "updatedAt": "2026-10-06T06:00:00.000Z"
  }
]
GET /products/:id PUBLIC
Menampilkan detail satu produk spesifik berdasarkan ID.
POST /products ADMIN ONLY
Menambahkan produk baru. Gunakan format form-data untuk mengunggah gambar.
Header: Content-Type: multipart/form-data
Form-Data Fields:
  • name (text, wajib): Nama produk
  • price (text/number, wajib): Harga produk (integer ≥ 0)
  • category (text, wajib): Kategori produk
  • stock (text/number, wajib): Jumlah stok (integer ≥ 0)
  • description (text, opsional): Deskripsi lengkap produk
  • image (file binary, opsional): File gambar (jpg, png, jpeg)
PATCH /products/:id ADMIN ONLY
Mengubah data produk & mengganti gambar (Content-Type: multipart/form-data).
DELETE /products/:id ADMIN ONLY
Menghapus data produk dari sistem berdasarkan ID.
6. Modul Pemesanan & Transaksi (`/orders`)
POST /orders USER LOGIN
Membuat order / transaksi checkout baru (stok otomatis dipotong).
Request Body (application/json)
{
  "productId": 1,
  "quantity": 2,
  "paymentMethod": "QRIS",   // "CASH" atau "QRIS"
  "shippingType": "NON_COD"  // Wajib "NON_COD" jika QRIS; Wajib "COD" jika CASH
}
Response Sukses (201 Created)
{
  "id": 15,
  "userId": 1,
  "totalAmount": 1300000,
  "status": "PENDING",
  "paymentMethod": "QRIS",
  "shippingType": "NON_COD",
  "createdAt": "2026-10-06T06:15:00.000Z",
  "orderItems": [
    {
      "id": 20,
      "productId": 1,
      "quantity": 2,
      "price": 650000,
      "product": {
        "id": 1,
        "name": "Sepatu Running Adidas",
        "imageUrl": "/uploads/product-171800000-12345.jpg"
      }
    }
  ]
}
GET /orders USER LOGIN
Menampilkan daftar seluruh riwayat pesanan milik user yang sedang login.
GET /orders/:id USER / ADMIN
Melihat detail 1 pesanan (hanya bisa dibuka oleh pemilik order atau admin).
PATCH /orders/:id/cancel PEMILIK ORDER
Membatalkan pesanan sendiri jika status masih PENDING. Stok produk otomatis dikembalikan.
GET /orders/admin/all ADMIN ONLY
Melihat semua pesanan dari seluruh pelanggan (dilengkapi detail user & barang).
PATCH /orders/:id/status ADMIN ONLY
Mengubah status pesanan oleh admin (contoh: konfirmasi bayar / pembatalan).
Request Body (application/json)
{
  "status": "PAID" // Pilihan: "PENDING", "PAID", "CANCELLED"
}
